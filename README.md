# Лабораторная работа №4: Собственные пакеты, документация и GitHub

## Вариант 3: `salarycalc` (Расчет зарплаты)

### Описание проекта
Проект реализует собственный пакет `salarycalc`, который позволяет:
1. Вычислять валовую зарплату (`GrossSalary`).
2. Рассчитывать чистую зарплату с учетом налогов (`NetSalary`).
3. Модифицировать значение чистой зарплаты через указатель с добавлением бонуса (`ApplyBonus`).
4. Форматировать и выводить итоговый отчет (`FormatSalaryReport`).

В проекте используются внешние сторонние библиотеки:
- `github.com/fatih/color` — для цветного логирования в терминале.
- `github.com/google/uuid` — для генерации уникального идентификатора сеанса.
